# Showcase images

`maya-bennett.jpg` is an AI-generated portrait of a synthetic person, created for
this InfoCard demonstration. It is not a photograph of a real contact.

`harbourview-business-centre.jpg` is an AI-generated architectural image of a
synthetic office building, seeded into the populated Account image column.
It does not depict an identifiable real building.

The Harbourview records, people, businesses and street address are synthetic.
Email and website addresses use reserved `example.com` domains; phone numbers
use UK drama ranges. Do not use this data for operational work or communications.

Both images are bundled locally, so rendering does not depend on an external
image service. Mobile offline image
availability still requires the profile's image column and a completed sync.
